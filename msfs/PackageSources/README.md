# MSFS EFB package sources

`VRChecklist/`, `efb_api/` and `vendor/` originate from the official MSFS 2024
SDK 1.7.3 EFB Template Sample. They are copied into this repository so the SDK
installation remains read-only.

Use the repository-level tasks documented in the root `README.md` to install,
build and deploy the app. Do not run builds in the installed SDK sample.
